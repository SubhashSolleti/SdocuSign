# API documents
OpenAPI 3 documents. The ones marked for the trial cover the Signora trial.

- 

## Administration APIUsed by the trial
Settings, audit, integrations and their credentials, webhooks, notifications,\ keys and platform storage.Download: Administration APIadmin.yaml · 591 KB
- 

## AI API
The AI gateway's registry (connections with write-only credentials,\ models, routes per feature and profile), usage with credits, the hosted allowance\ and its notices, the model-quality report, consented samples, on-device models\ delivered over the air and their training runs -- the tenant's own and the operator's.Download: AI APIai.yaml · 303 KB
- 

## Apps API
The app builder: workspaces, apps, pages, versions and checkpoints,\ export and import.Download: Apps APIapps.yaml · 187 KB
- 

## Authentication APIUsed by the trial
Access tokens for integrations (OAuth 2 client credentials), accepting\ an invitation, resetting a password and switching tenant.Download: Authentication APIauth.yaml · 13 KB
- 

## Content API
Content repository: types, objects, versions, transfers, access control,\ query and reports.Download: Content APIcontent.yaml · 791 KB
- 

## Correspondence API
The Correspondence product: the register, the desk, positions and\ dispatch.Download: Correspondence APIcorrespondence.yaml · 92 KB
- 

## Generation API
Document generation: the templates a member can use, their value schemas,\ generation into a new document or the next version, bulk generation from rows\ or CSV, and recorded requests by key.Download: Generation APIgeneration.yaml · 28 KB
- 

## Present API
The presentation product: decks as documents -- open by id, list,\ create, save a version.Download: Present APIpresent.yaml · 31 KB
- 

## Search API
The search component: the content administrator's index view (the\ engine, the tenant's index and its lag, pending and failed items with retry,\ re-index) and questions across documents.Download: Search APIsearch.yaml · 19 KB
- 

## Sign APIUsed by the trial
The external signer's page: the envelope as its signer sees it, consent,\ verification, fields, finish, decline, delegate and the envelope's documents\ at their pinned versions.Download: Sign APIsign.yaml · 57 KB
- 

## Signing APIUsed by the trial
The sender's envelopes: create, replace while a draft, send, void,\ resend, read, the lists, the certificate of completion and the sealed documents.Download: Signing APIsigning.yaml · 195 KB
- 

## Vault API
The Vault product: preferences, saved searches, home perspectives\ and widgets, packs, favourites and recents.Download: Vault APIvault.yaml · 72 KB
- 

## Workflow API
Definitions and versions, runs and their events, human tasks, signals,\ secrets, the palette and reports.Download: Workflow APIworkflow.yaml · 303 KB
