## Content services

- 
### Organise
Cabinets and folders hold typed documents and records. Properties are declared on the type, and a folder type can pass its properties down to everything filed in it.
- 
### Govern
Permissions per folder and document with inheritance, named access lists, retention schedules, legal holds that block change and retention that blocks destruction.
- 
### Find
Full-text search over document bodies on the database for every customer, and a licensed search engine with facets, suggestions, synonyms and hybrid search that never widens what a person may see.
- 
### Understand
Classification, field extraction with the quotes it relied on, summaries and questions on a document, marked as suggested until a person accepts them.

## What it does

### Capture
- Upload, or scan from the browser through the scan agent
- Per-type processing after upload: virus scan, text extraction, image clean-up, OCR only where needed, classification, indexing
- Three OCR tiers, including Arabic and a vision model through the AI gateway

### Work
- Versions and renditions with a document viewer
- Share and Shared with me, invitations and groups
- Generate documents from Word or HTML templates, alone or in bulk
- Send for signature with Signora

### Keep
- Lifecycle states and rules
- Retention schedules and dispositions, legal holds, object lock on the storage
- An audit trail with a daily digest chain you can verify

## What is different about TroveDocs
Not a file cabinet: documents that answer. Finding is no longer a job; governance is no longer a project.

- 
### AI answers with their quotes
Extracted fields and summaries carry the passages they came from, so a reviewer checks the source rather than trusting the model.
- 
### Search that cannot leak
The database decides permissions; the search index is a disposable projection that can never widen what a person sees.
- 
### Processing you configure
A small office with plain PDFs runs nothing extra; an archive with scans runs clean-up and OCR. The choice is per document type.
- 
### Arabic as a first language
Arabic OCR, bilingual screens and right-to-left layout are part of the product, not a localisation pack.

## Questions to ask any document management vendor

Our answers, each from our design records. Use the same questions to compare.
QuestionTroveDocs
Can it run on our own servers?Yes, on-prem with the same build as the hosted service.
Which AI model reads our documents?The one your administrator configures per organisation, including a model you host.
Can search show a document a person may not open?No. Permissions come from the database, not the index.
Is OCR run on every file?Only where the document type's pipeline asks for it and the file needs it.
How are records kept?Retention schedules, legal holds and object lock on the storage.

## Questions

### When is TroveDocs available?+
It is in development and is not part of the current trial. Ask for a preview and we will show it on our stack.

### Does it need a search engine?+
No. Full-text search runs on the database for everyone. The licensed search engine adds facets, suggestions and hybrid search.

### Does it work without AI?+
Yes. Every feature that does not call a model works without one; the AI features switch on when a model is configured.
