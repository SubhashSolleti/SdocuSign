## Signora trial release notes (November 2026)
Signora is an electronic-signature application: a sender prepares documents, names the people who must sign, approve or receive a copy, and sends them; each person signs on a web page or in the mobile app; the platform seals every signed document with a PAdES-B-LT signature (an RFC 3161 time stamp and validation data embedded in the PDF), appends a certificate of completion, and keeps an evidence trail.Read: Signora trial release notes (November 2026)
